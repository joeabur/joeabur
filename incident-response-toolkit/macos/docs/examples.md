# Examples (synthetic data)

Run from the `macos/` directory with the virtualenv active. These work on any OS and need no privileges or network.

```bash
python -m mac_ir verify-manifest --input examples/synthetic-evidence/case-001
python -m mac_ir scan --input examples/synthetic-evidence/case-001
python -m mac_ir scan --input examples/synthetic-evidence/case-001 \
  --iocs examples/iocs.json --baseline examples/synthetic-evidence/baseline --json
python -m mac_ir scan --input examples/synthetic-evidence/case-001 --fail-on-findings; echo $?   # 10
python -m mac_ir report --input examples/synthetic-evidence/case-001 --iocs examples/iocs.json \
  --output /tmp/mac-ir-report-example
python -m mac_ir seal --input ./my-imported-evidence
python -m mac_ir collect --dry-run --profile extended --output ./evidence
python -m mac_ir --config configs/detections.yaml collect --profile persistence-review --dry-run --output ./evidence
```

On a test Mac (read-only):

```bash
python -m mac_ir collect --collectors logs --log-hours 6 --output ./evidence
python -m mac_ir collect --collectors logs --import-archive ./case.logarchive --output ./evidence
python -m mac_ir collect --collectors logs --import-log ./export.ndjson --output ./evidence
```

Files: [`examples/iocs.json`](../examples/iocs.json), [`examples/synthetic-evidence/`](../examples/synthetic-evidence),
[`examples/expected-results/`](../examples/expected-results). The synthetic evidence is generated by
[`scripts/make-synthetic-evidence.py`](../scripts/make-synthetic-evidence.py) from an invented fake macOS filesystem and fake
command output ([`tests/fixtures/rootfs_builder.py`](../tests/fixtures/rootfs_builder.py)): RFC 5737 IPs, `*.example.test`
domains and a harmless text file in place of malware. **The synthetic evidence is not output from a real Mac**; owner names
reflect the machine that generated the fixtures.
