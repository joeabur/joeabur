# Examples (synthetic data)

All commands run from the `windows/` directory and need no privileges or network access.

```powershell
Import-Module ./src/Modules/WinIRToolkit/WinIRToolkit.psd1 -Force

# Verify the committed synthetic evidence
Test-IREvidenceManifest -Path ./sample-data/case-001 | Format-List

# Detections only / with IOCs and a baseline / as JSON for automation
./scripts/winir.ps1 -Command Scan -InputPath ./sample-data/case-001
./scripts/winir.ps1 -Command Scan -InputPath ./sample-data/case-001 -IocPath ./examples/iocs.json -BaselinePath ./sample-data/baseline
./scripts/winir.ps1 -Command Scan -InputPath ./sample-data/case-001 -Json | ConvertFrom-Json | Group-Object severity

# Fail a CI job when anything is found (exit code 10)
./scripts/winir.ps1 -Command Scan -InputPath ./sample-data/case-001 -FailOnFindings; $LASTEXITCODE

# Reports (JSON + CSV + HTML)
./scripts/winir.ps1 -Command Report -InputPath ./sample-data/case-001 -IocPath ./examples/iocs.json -OutputPath ./reports/example

# Use the pieces directly
$ioc = Import-IRIoc ./examples/iocs.json
$a = Invoke-IRAnalysis -Path ./sample-data/case-001
Find-IRIocMatch -Artifacts $a.Artifacts -Indicators $ioc.Indicators | Select-Object rule_id, evidence_ref -First 3
Import-IRRule | Where-Object { $_.Raw.category -eq 'persistence' } | Measure-Object

# Seal hand-made evidence (artifacts only) so it can be verified
Protect-IREvidenceDirectory -Path ./my-imported-evidence

# Dry run, custom profile from a configuration file
./scripts/winir.ps1 -Command Collect -Profile FocusedIncident -OutputPath ./evidence -DryRun
./scripts/winir.ps1 -Command Collect -Profile RdpReview -ConfigPath ./examples/config.example.json -OutputPath ./evidence -DryRun
```

On a test Windows machine (read-only):

```powershell
./scripts/winir.ps1 -Command Collect -Profile PersistenceReview -OutputPath ./evidence
(Get-IREventLog -Log Security -Hours 6).Errors      # shows permission_denied when not elevated
```

Files: [`examples/iocs.json`](../examples/iocs.json), [`examples/config.example.json`](../examples/config.example.json),
[`sample-data/`](../sample-data), [`examples/expected-results/`](../examples/expected-results). The sample data is generated by
[`scripts/New-SyntheticEvidence.ps1`](../scripts/New-SyntheticEvidence.ps1) from invented data sources
([`tests/Fixtures/FakeWindows.ps1`](../tests/Fixtures/FakeWindows.ps1)); it is **not** output from a real Windows host.
